# Week 01：Java 基础

本目录记录第一周的 Java 基础练习。每个子目录都是一个可独立编译运行的小练习。

## 练习索引

| 路径 | 内容 |
| --- | --- |
| `HelloWorld.java` | 变量、比较运算和布尔值输出 |
| `first-project` | Hello World 与程序入口 |
| `second-project` | 基础控制台输出 |
| `third-project` | 水仙花数 |
| `4-project` | 九九乘法表 |
| `5-project` | 斐波那契数列 |
| `forth-project` | `Player` 类与对象之间的方法调用 |

编译产物统一放入各项目的 `bin` 目录；`bin`、`.class`、`.vscode` 和 `.DS_Store` 已由仓库根目录的 `.gitignore` 忽略。
